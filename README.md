# Multi Class Segmentation LinkNet
# [TR]
## Proje Hakkında
Bu proje, **32 sınıflı (multi-class) semantik segmentasyon** problemini çözmek için hazırlanmıştır. LinkNet mimarisini kullanrak veri seti üzerinde eğitim yaptım ve eğitim sonucunda oluşan model ile tahminler yaptım.

## ⚡ Kullanılan Teknolojiler
- PyTorch
- Python
- LinkNet

## 🖼️ Veri Seti
- Veri seti [buradan](https://www.kaggle.com/datasets/carlolepelaars/camvid) indirilebilir.
- Eğitim ve test verileri klasörlere ayrılmıştır:  
  - `train/` : Eğitim görüntüleri  
  - `train_labels/` : Eğitim maskeleri  
  - `test/`  : Test görüntüleri  
  - `test_labels/`  : Test maskeleri
  - `val/`  : Doğrulama görüntüleri  
  - `val_labels/`  : Doğrulama maskeleri

# [EN]
## About the Project
This project is designed to solve a 32-class (multi-class) semantic segmentation problem. I trained the model on the dataset using the LinkNet architecture, and used the trained model to make predictions.

## ⚡ Technologies Used
- PyTorch
- Python
- LinkNet

## 🖼️ Dataset
The dataset can be downloaded [here](https://www.kaggle.com/datasets/carlolepelaars/camvid)

- Training and test data are organized into folders:
- `train/` : Training images
- `train_labels/` : Training masks
- `test/` : Test images
- `test_labels/` : Test masks
- `val/` : Validation images
- `val_labels/` : Validation masks
